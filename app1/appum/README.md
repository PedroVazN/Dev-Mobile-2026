# Vizzy Sanca (MVP)

Rede social de **negócios locais de São Caetano do Sul** (apelido **Sanca**) — promoções, cupons, chat e painéis para consumidor, loja e administrador.

## Cidade foco

- **Município:** São Caetano do Sul — ABC Paulista  
- **Bairros no app:** Centro, Santa Paula, Cerâmica, Barcelona, Olímpico, São José, Fundação  
- **Referências locais:** ParkShopping, Teatro Paulo Machado de Carvalho, Espaço Verde Chico Mendes  

Dados e coordenadas em `constants/city.ts`.

## Executar

```bash
cd app1/appum
npm install
npm start
```

Abra no **Expo Go** escaneando o QR code.
